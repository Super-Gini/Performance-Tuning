# ORA-12505: TNS: listener does not currently know of SID

## Overview

Client connected to the listener successfully, but requested a SID the listener doesn't know about. Usually indicates:

- Wrong SID in connect string.
- Instance not registered with this listener.
- Instance registered with a different SID than expected.
- Client using SID when service is what's registered.

## Diagnostic Steps

### 1. What does the listener know?

```bash
lsnrctl services
lsnrctl status
```

Look for the SID you're trying to reach. If not listed, the instance isn't registered here.

### 2. Client's connect string

```
(CONNECT_DATA = (SID = orcl))   # SID-based
```

vs

```
(CONNECT_DATA = (SERVICE_NAME = orcl.corp.example.com))   # service-based
```

### 3. Verify instance parameters

```sql
SHOW PARAMETER instance_name
SHOW PARAMETER service_names
SHOW PARAMETER local_listener
SHOW PARAMETER db_name
```

## Common Fixes

### Use SERVICE_NAME instead

Modern practice: use `SERVICE_NAME`, not `SID`:

```
PROD =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL=TCP)(HOST=dbhost)(PORT=1521))
    (CONNECT_DATA = (SERVICE_NAME = prod.corp.example.com)))
```

### Force registration

```sql
ALTER SYSTEM REGISTER;
```

Then re-check `lsnrctl services`.

### Fix `local_listener`

If instance is registering elsewhere (or nowhere):

```sql
ALTER SYSTEM SET local_listener = '(ADDRESS=(PROTOCOL=TCP)(HOST=dbhost)(PORT=1521))' SCOPE=BOTH;
ALTER SYSTEM REGISTER;
```

### Static entry (if pre-open access needed)

Add to `listener.ora`:

```
SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC =
      (SID_NAME = orcl)
      (ORACLE_HOME = /u01/app/oracle/product/19.0.0/dbhome_1)
      (GLOBAL_DBNAME = orcl.corp.example.com)))
```

Reload: `lsnrctl reload`.

Needed for RMAN when database is NOMOUNT.

### Timing after startup

LREG registers within 60 seconds after startup. Wait or force register.

## Distinguishing from ORA-12514

- `ORA-12505` — listener doesn't know the **SID**.
- `ORA-12514` — listener doesn't know the **service**.

## Best Practices

1. **Use SERVICE_NAME** — SID is legacy.
2. **Enable dynamic registration** — LREG handles service ↔ listener mapping.
3. Static entries only for RMAN NOMOUNT / extproc.
4. `srvctl` manages listener + instance registration in RAC.
5. After any restart, verify `lsnrctl services` shows expected services.

## Interview Questions

1. **Q:** `ORA-12505` vs `ORA-12514`?
   **A:** 12505 = SID unknown. 12514 = SERVICE unknown.

2. **Q:** Should apps connect by SID or SERVICE?
   **A:** SERVICE_NAME — works with RAC, DG, PDBs.

3. **Q:** When do you need a static SID entry?
   **A:** RMAN restore of NOMOUNT instance, external procedures.

4. **Q:** How long does LREG take to register?
   **A:** Immediately on OPEN, then every 60s. `ALTER SYSTEM REGISTER;` for immediate.
