# ORA-03113: end-of-file on communication channel

## Meaning

The Oracle server process died or was killed while the client was waiting for a response.

```
ORA-03113: end-of-file on communication channel
Process ID: 12345
Session ID: 150 Serial number: 32458
```

## Common Causes

- Server process crashed (ORA-07445 usually accompanies).
- ORA-00600 internal error.
- Session killed by admin or Resource Manager.
- Session hit `IDLE_TIME` / `INACTIVE` cutoff.
- Server process OOM-killed by Linux (check `dmesg`).
- Network issue mid-flight.
- Instance crashed.

## Diagnostic Queries

Immediately check:

```sql
-- Instance alive?
SELECT status, database_status FROM v$instance;

-- Recent errors
SELECT originating_timestamp, message_text
FROM   v$diag_alert_ext
WHERE  originating_timestamp > SYSDATE - 1/24
   AND (message_text LIKE '%ORA-00600%' OR message_text LIKE '%ORA-07445%'
        OR message_text LIKE '%killed%')
ORDER  BY originating_timestamp DESC;

-- Recent incidents
SELECT incident_id, problem_key, error_facility, create_time
FROM   v$diag_incident
WHERE  create_time > SYSDATE - 1/24
ORDER  BY create_time DESC;
```

OS side:

```bash
# Kernel OOM
dmesg | tail -100 | grep -i oracle

# Recent Oracle process crash
ls -lat $ORACLE_BASE/diag/rdbms/*/*/incident/ | head
```

## Fix

**Just this session** — reconnect and continue.

**ORA-07445 / 00600** — See [ORA-00600](ora-00600.md), [ORA-07445](ora-07445.md).

**Session killed by Resource Manager**:

```sql
SELECT plan, group_or_subplan, switch_group, switch_time, switch_estimate
FROM   dba_rsrc_plan_directives
WHERE  plan = (SELECT value FROM v$parameter WHERE name='resource_manager_plan');
```

Adjust `switch_group` or raise the query's group priority.

**OOM-killed** — Reduce PGA per session, or grow host memory. Add `oracle` to OOM-killer exempt list (Linux).

**Instance crashed** — check alert log; instance auto-restart via `srvctl` / `crsctl`.

**Network mid-flight** — check `SQLNET.EXPIRE_TIME`, TCP keepalive, firewall session timeouts.

## Prevention

- Monitor alert log for ORA-00600 / 07445 patterns.
- Set `oom_score_adj = -100` on `oracle` user in `/etc/security/limits.d/`.
- Reasonable `SESSIONS_PER_USER` and `IDLE_TIME` in profiles.
- Modern RUs — many crash bugs fixed.
- Application: retry on ORA-03113 with fresh connection.
