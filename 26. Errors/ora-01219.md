# ORA-01219: database or pluggable database not open: queries allowed on fixed tables/views only

## Meaning

Query against a regular table on a DB that isn't `OPEN`. Only `V$` and `X$` views are queryable when the DB is `MOUNT`ed.

```
ORA-01219: database or pluggable database not open: queries allowed on fixed tables/views only
```

## Common Causes

- Startup in progress.
- Recovery running.
- PDB is closed.
- `STARTUP MOUNT` intentional.

## Fix

**Regular DB**:

```sql
SELECT open_mode FROM v$database;   -- fine
SELECT * FROM dba_users;            -- ORA-01219
```

Solution — open it:

```sql
ALTER DATABASE OPEN;
```

**Pluggable DB**:

```sql
SELECT name, open_mode FROM v$pdbs;

ALTER PLUGGABLE DATABASE PDB1 OPEN;
-- or
ALTER PLUGGABLE DATABASE ALL OPEN;
```

**Recovery in progress**:

```sql
SELECT * FROM v$recovery_progress;
-- Wait for it, or complete it:
ALTER DATABASE RECOVER AUTOMATIC;
```

**Read-only intentional** — this error only says "not open"; if open in `READ ONLY` you'll get ORA-16000 for writes but not this error.

## Prevention

- Startup scripts open PDBs explicitly.
- Save-state on PDBs so they open automatically on CDB start:
  ```sql
  ALTER PLUGGABLE DATABASE PDB1 SAVE STATE;
  ```
