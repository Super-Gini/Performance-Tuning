# ORA-12541: TNS:no listener

## Meaning

Client reached the DB host, but nothing is listening on the target port.

```
ORA-12541: TNS:no listener
```

## Common Causes

- Listener not started.
- Listener bound to different host/port.
- Firewall blocking.
- Wrong hostname/IP in TNS descriptor.
- Listener crashed.

## Diagnostic

Server side:

```bash
lsnrctl status
ps -ef | grep tnslsnr
netstat -tlnp | grep 1521
```

Client side:

```bash
telnet <db_host> 1521
tnsping <alias>
```

## Fix

**Start the listener**:

```bash
lsnrctl start
# or specific
lsnrctl start LISTENER_PRD
```

**Wrong port** in tnsnames.ora — correct the port to match the listener.

**Wrong host** — DNS / `/etc/hosts` fix.

**Firewall**:

```bash
# On the DB host (Linux)
firewall-cmd --add-port=1521/tcp --permanent
firewall-cmd --reload
```

Ask security team for network firewall exception.

**Listener crashed**:

```bash
# Check log
tail -100 $ORACLE_BASE/diag/tnslsnr/<host>/listener/trace/listener.log

# Restart
lsnrctl start
```

## Prevention

- Auto-start listener on host boot (`srvctl` on RAC/GI, systemd unit on standalone).
- Monitor listener alive (`lsnrctl status | grep TNS-`).
- Alert on port 1521 down.
- Firewall changes documented.
