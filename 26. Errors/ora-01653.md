# ORA-01653: unable to extend table %s.%s by %s in tablespace %s

## Meaning

A table couldn't grow — the tablespace is full and no datafile can extend.

```
ORA-01653: unable to extend table APP.ORDERS by 128 in tablespace USERS
```

## Common Causes

- Tablespace at max size, no autoextend room.
- Datafiles hit `MAXBYTES`.
- Filesystem full.
- ASM diskgroup full.
- Quota reached on the user for that tablespace.

## Diagnostic Queries

```sql
-- Tablespace fill
SELECT   df.tablespace_name,
         ROUND(SUM(df.bytes)/1024/1024/1024, 2) alloc_gb,
         ROUND((SUM(df.bytes)-NVL(SUM(fs.bytes),0))/1024/1024/1024, 2) used_gb,
         ROUND((SUM(df.bytes)-NVL(SUM(fs.bytes),0))*100/SUM(df.bytes), 2) pct_used,
         ROUND(SUM(df.maxbytes)/1024/1024/1024, 2) max_gb
FROM     dba_data_files df
LEFT JOIN (SELECT tablespace_name, SUM(bytes) bytes FROM dba_free_space
           GROUP BY tablespace_name) fs USING (tablespace_name)
GROUP BY df.tablespace_name
ORDER BY 4 DESC;

-- Datafiles autoextend info
SELECT file_name,
       ROUND(bytes/1024/1024/1024,2) size_gb,
       ROUND(maxbytes/1024/1024/1024,2) max_gb,
       autoextensible, increment_by
FROM   dba_data_files
WHERE  tablespace_name = '&tablespace';

-- User quota
SELECT tablespace_name, ROUND(bytes/1024/1024,2) used_mb,
       DECODE(max_bytes,-1,'UNLIMITED',ROUND(max_bytes/1024/1024,2)) max_mb
FROM   dba_ts_quotas WHERE username = '&user';

-- Filesystem free
!df -h /u01
```

## Fix

**Extend datafile**:

```sql
ALTER DATABASE DATAFILE '/u01/oradata/PRD/users01.dbf' RESIZE 30G;
```

**Add datafile**:

```sql
ALTER TABLESPACE USERS ADD DATAFILE '/u01/oradata/PRD/users02.dbf'
    SIZE 20G AUTOEXTEND ON MAXSIZE 50G;
```

**Enable autoextend**:

```sql
ALTER DATABASE DATAFILE '/u01/oradata/PRD/users01.dbf' AUTOEXTEND ON MAXSIZE 100G;
```

**Convert to bigfile** (very large):

```sql
CREATE BIGFILE TABLESPACE USERS_BIG DATAFILE '/u01/oradata/PRD/users_big.dbf' SIZE 100G AUTOEXTEND ON;
ALTER TABLE app.orders MOVE TABLESPACE USERS_BIG;
```

**User quota**:

```sql
ALTER USER app QUOTA UNLIMITED ON USERS;
```

## Prevention

- Autoextend on all datafiles, with sensible MAXBYTES.
- Alert on tablespace 80% / 95%.
- Filesystem alerting (Oracle can't extend on a full FS).
- Bigfile tablespaces for large single-file data.
