# ORA-00257: archiver error. Connect internal only, until freed

## Meaning

The archiver process cannot copy the current online redo log to any archive destination — usually because a destination is full or offline. Once all archive destinations are unusable, LGWR stops (can't switch logs), and the database freezes for user connections.

```
ORA-00257: archiver error. Connect internal only, until freed.
```

## Common Causes

- FRA (`DB_RECOVERY_FILE_DEST`) full.
- Archive log filesystem 100% full.
- Archive destination path invalid.
- Data Guard standby destination unreachable and DEFER mode not set.
- RMAN retention keeping too many archives.

## Diagnostic Queries

Connect as `SYS`:

```sql
-- Destination status
SELECT   dest_id, dest_name, destination, status, error, log_sequence
FROM     v$archive_dest
WHERE    status <> 'INACTIVE';

-- FRA
SELECT   name, ROUND(space_used*100/space_limit,2) pct_used,
         ROUND(space_reclaimable*100/space_limit,2) pct_reclaim
FROM     v$recovery_file_dest;

-- Archives not yet backed up
SELECT COUNT(*), ROUND(SUM(blocks*block_size)/1024/1024/1024, 2) gb
FROM   v$archived_log
WHERE  deleted = 'NO' AND backup_count = 0;
```

## Fix

**FRA full** — backup + delete archived logs:

```bash
rman target /

RMAN> BACKUP ARCHIVELOG ALL DELETE INPUT;
# or
RMAN> DELETE NOPROMPT ARCHIVELOG UNTIL TIME 'SYSDATE - 3';
RMAN> DELETE OBSOLETE;
RMAN> CROSSCHECK ARCHIVELOG ALL;
RMAN> DELETE EXPIRED ARCHIVELOG ALL;
```

**Emergency space clearing** (be sure it's backed up first!):

```bash
# Confirm backup exists
rman target / <<EOF
LIST BACKUP OF ARCHIVELOG UNTIL TIME 'SYSDATE-1';
EOF

# Then in RMAN
DELETE NOPROMPT ARCHIVELOG UNTIL TIME 'SYSDATE-1' BACKED UP 1 TIMES TO DISK;
```

**Change destination**:

```sql
ALTER SYSTEM SET log_archive_dest_1 = 'LOCATION=/u02/new_archive' SCOPE=BOTH;
ALTER SYSTEM ARCHIVE LOG START;
```

**Increase FRA size**:

```sql
ALTER SYSTEM SET db_recovery_file_dest_size = 1T SCOPE=BOTH;
```

**Defer bad Data Guard dest**:

```sql
ALTER SYSTEM SET log_archive_dest_state_2 = DEFER SCOPE=BOTH;
```

## Prevention

- Alert on FRA % used ≥ 80%.
- RMAN retention policy that includes archive cleanup.
- Multiple archive destinations (local + remote).
- Standby monitored — DEFER unreachable destinations before they cause ORA-00257.
